# 🚀 Guía Completa: Crear un Proyecto Web con Kiro + Supabase + Vercel

Esta guía te lleva paso a paso para crear una web desde cero usando:
- **Kiro** como tu asistente de desarrollo (IA)
- **Supabase** como base de datos y autenticación
- **Vercel** como hosting (tu web online gratis)
- **GitHub** como repositorio de código

---

## 📁 Estructura de esta guía

| Archivo | Qué contiene |
|---------|-------------|
| [01-supabase-setup.md](./01-supabase-setup.md) | Crear cuenta en Supabase, conectar la base de datos |
| [02-vercel-github-setup.md](./02-vercel-github-setup.md) | Crear cuenta en Vercel, conectar GitHub, deploy automático |
| [03-kiro-steering-files.md](./03-kiro-steering-files.md) | Cómo crear archivos .md para que Kiro entienda tu proyecto |
| [04-kiro-custom-agents.md](./04-kiro-custom-agents.md) | Crear agentes especializados (experto en vinos, investigador, etc.) |
| [05-mcp-connections.md](./05-mcp-connections.md) | Conectar Kiro a Supabase y GitHub vía MCP |
| [06-deploy-workflow.md](./06-deploy-workflow.md) | Flujo completo: código → GitHub → Vercel (web actualizada) |
| [07-tips-importantes.md](./07-tips-importantes.md) | Tips, errores comunes, y buenas prácticas |

---

## 🎯 Resultado final

Al terminar esta guía tendrás:
1. ✅ Una base de datos en Supabase (gratis)
2. ✅ Un repositorio en GitHub con tu código
3. ✅ Una web online en Vercel que se actualiza automáticamente al hacer push
4. ✅ Kiro configurado para entender tu proyecto y ayudarte
5. ✅ Agentes especializados que Kiro puede usar
6. ✅ Conexiones directas a tu DB y GitHub desde Kiro

---

## ⚡ Requisitos previos

- Cuenta de Google (para login en Supabase y Vercel)
- GitHub cuenta (gratis) — github.com
- VS Code o Kiro IDE instalado
- Node.js instalado (nodejs.org → versión LTS)

---

## 🏁 Por dónde empezar

1. Lee los archivos en orden (01, 02, 03...)
2. Cada archivo tiene pasos numerados
3. Si te atascas, pídele a Kiro: "Ayúdame con el paso X de la guía"
4. Los bloques de código se pueden copiar directamente

¡Vamos! 🎉
